# mlops-git-assignment-Guangyuan-Gao
# Project description
Our project is to develop a housing price prediction model using Ames housing price dataset. It has 1460 data in training and 79 features. The model we choose to use is CatBoost which can handle lots of categorical features well.
# Set up and prerequisite
To initialize this project, go to the linked website to download the data csv file. We use python in JupyterNotebook in Anaconda platform so please ensure this is installed locally.
